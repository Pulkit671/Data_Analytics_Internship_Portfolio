# Data Analytics Internship Portfolio

## Overview
This project represents an end-to-end data analytics workflow including data cleaning, exploratory data analysis, dashboard creation, and data storytelling.

## Task 1: Data Wrangling
- Cleaned and prepared dataset
- Handled missing values and inconsistencies

## Task 2: Exploratory Data Analysis
- Performed statistical analysis
- Created visualizations to understand patterns

## Task 3: Dashboard
- Built an interactive Power BI dashboard
- Analyzed customer behavior and KPIs

## Task 4: Data Storytelling & Statistical Validation
- Developed business insights from data
- Applied hypothesis testing
- Created a structured narrative for decision-making

## Key Insights

- Customer engagement increases purchase frequency

- Python (Pandas, Matplotlib)
- Power BI
- SQL
- GitHub

## Conclusion
This internship project demonstrates the complete data analytics lifecycle from data preparation to business insights.
