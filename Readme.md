# Data Analytics Internship Portfolio

## 📌 Overview
This portfolio showcases an end-to-end Data Analytics Internship project, covering data cleaning, exploratory analysis, interactive dashboard creation, and business-driven data storytelling.

The project focuses on analyzing customer data to uncover patterns in income, spending behavior, and customer value for better decision-making.

## Task 1: Data Wrangling
- Cleaned and prepared dataset
- Handled missing values and inconsistencies

## Task 2: Exploratory Data Analysis
- Performed statistical analysis
- Created visualizations to understand patterns

## Task 3: Dashboard
- Built an interactive Power BI dashboard
- Analyzed customer behavior and KPIs

## Task 4: Data Storytelling & Statistical Validation
- Developed business insights from data
- Applied hypothesis testing
- Created a structured narrative for decision-making

## 🔍 Key Insights
- Higher income customers contribute significantly to overall customer value  
- Customer engagement (membership duration) directly increases purchase frequency  
- Customer behavior varies across different segments, enabling targeted strategies
